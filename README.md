# 🐍💧🔫 Snake Water Gun Game

A simple Command Line Interface (CLI) game developed using Python that simulates the classic **Snake-Water-Gun** game, similar to Rock-Paper-Scissors.

The player competes against the computer, which randomly selects its move. The program then determines the winner based on predefined game rules.

## 🚀 Features

- Interactive CLI gameplay
- Random computer move generation
- Winner determination logic
- Tie detection
- Beginner-friendly Python project

## 🛠️ Technologies Used

- Python 3
- Random Module

## 🎮 Game Rules

| Choice | Beats |
|---------|--------|
| Snake 🐍 | Water 💧 |
| Water 💧 | Gun 🔫 |
| Gun 🔫 | Snake 🐍 |

### Examples

- Snake vs Water → Snake Wins
- Water vs Gun → Water Wins
- Gun vs Snake → Gun Wins
- Same choice → Tie
